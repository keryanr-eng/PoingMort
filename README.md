# Poing Mort

Jeu PC solo en 3D à la troisième personne (Unity 6, URP) : un petit quartier où les voitures
autonomes ne s'arrêtent jamais, des combats aux poings et des courses.

> Travail en cours sur le jalon **P01** (première preuve jouable). Le README complet
> (ouverture du projet, commandes, limites) arrive avec la livraison du jalon.
